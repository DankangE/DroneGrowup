# 보드 플레이 제안 (인생 보드게임식 진행)

**variant C implemented (engine, part 1 of 3)**. 현재 엔진의 칸 배치, 계절 규칙과 실측 밸런스는 [현행 기획서](../design.md)에 있다. 아래는 설계 당시 검토한 대안과 시간 추정 기록이다.

사용자 요청: 룰렛을 돌려 말을 N칸 옮기고, 멈춘 칸이 일감 · 사건 · 월급 · 선택을 일으키고, 갈림길(이론 코스 대
실전 코스, 안전 항로 대 위험 항로)과 직업 카드 · 승급이 있고, 마지막에 자산과 업적으로 순위를 매기는 진행.
참고하는 것은 진행 방식뿐이다. 칸 이름, 그림, 문구는 모두 이 게임의 것을 새로 만든다.

## 1. 한 턴

1. **돌린다**: 1~6 룰렛(0.7초, 누르면 바로 멈춤). 굴림은 엔진의 시드 RNG가 정하고 화면은 결과만 그린다.
2. **움직인다**: 말이 칸을 하나씩 지난다. 지나가기만 해도 발동하는 칸은 월급 칸뿐이다(지나갈 때 월급 · 이자 정산).
3. **멈춘다**: 멈춘 칸의 종류가 선택지를 정한다. 갈림길은 멈추지 않아도 지날 때 길을 고른다.
4. **해결한다**: 지금의 `options` / `forecast` / `choose`를 그대로 쓴다. 칸이 내놓는 선택지만 다를 뿐 카드,
   확률 표시, 결과 줄(`outcome-text.ts`)은 같다.

## 2. 보드 모양

| 안 | 모양 | 장점 | 단점 |
|---|---|---|---|
| 한 해 한 바퀴 | 20칸짜리 고리, 봄 · 여름 · 가을 · 겨울 구간 5칸씩. 바퀴마다 같은 칸 | 화면 하나에 다 보임(지금 계절 보드와 같은 자리), 모바일에 맞음 | 칸이 반복되어 같은 그림이 자주 보임 |
| 인생 한 길 | 20세~50세를 잇는 긴 길 하나, 중간에 갈림길 | 진행감, 갈림길이 눈에 보임 | 화면에 다 안 들어가 스크롤 또는 확대가 필요(스크롤 금지 규칙과 충돌) |

추천: **한 해 한 바퀴**. 갈림길은 고리 안의 짧은 우회로(3~4칸)로 넣고, 직업 단계가 바뀌면 고리의 칸 구성(일감 칸의
종류, 승급 칸 위치)을 바꿔 반복감을 줄인다. 이 방식이면 "아무것도 스크롤하지 않는다"는 규칙을 지킨다.

## 3. 칸 종류

| 칸 | 하는 일 | 지금 게임에서 가져오는 것 |
|---|---|---|
| 훈련 | 이론 · 조종 실력을 올리는 행동 1~2개 중 하나 | `ACTIONS`의 수업 · 시뮬레이터 · 실기 |
| 일감 | 비행 일감 하나를 받거나 넘긴다(굴림) | `ACTIONS`의 job_* 와 비행 · 추락 규칙 |
| 대회 · 시험 | 자격증 시험, 대회(굴림, 상금 · 평판) | 자격증 과정, 대회 이벤트 |
| 월급 | 지나가면 월급 · 생활비 · 이자 정산 | 지금의 계절 정산(`settlementText`) |
| 사건 | 돌발 이벤트 하나 | `EVENTS` 38개(공짜 선택지 규칙 유지) |
| 휴식 | 체력 회복, 정비 할인 | `rest` |
| 갈림길 | 길 선택: 이론 코스 / 실전 코스, 안전 항로 / 위험 항로 | 새로 만듦(우회로 칸 구성) |
| 승급 | 조건을 채웠으면 단계 · 직급이 오른다 | `career.ts` 승급 카드, `STAGES` |

## 4. 지금 시스템이 들어가는 자리

- **G~S 능력치, 자금, 빚, 체력**: 그대로. 칸이 내놓는 선택지가 지금의 행동이므로 확률과 보정도 그대로다.
- **엔딩 11개**: 그대로. 50세 또는 조기 엔딩 조건(협회장, 교육원장, 빚쟁이 등)으로 끝난다.
- **점수**: 지금도 `순자산 + 엔딩 보너스(+ 조기 엔딩 계절 보너스)`이다. 여기에 업적(완주한 갈림길, 대회 우승
  수)을 작은 보너스로 더하면 "자산과 업적으로 순위"가 된다.
- **승급 카드**: 승급 칸에 멈추거나 지날 때 띄운다.
- **outcome-text**: 칸의 선택지 카드와 결과 시트에 그대로 쓴다. `npm run outcomes` 검사도 그대로 돈다.
- **NalidaGame 상한**: MAX_TURNS 120, 나이 20~50, acts 0~99, wins + losses <= 8 x turns + 10,
  flights <= 5 x turns, MAX_SCORE 340000. 아래 변형별 영향 참고.

## 5. 변형 세 가지

시간 추정은 `npm run simulate`의 지금 수치(판당 평균 105.6계절, 계절당 행동 2.02번, 이벤트 0.37번)에 같은
시간 모형(행동 4.5초, 이벤트 8초, 정산 2~3초)과 룰렛 · 이동 3초, 칸 해결 5초를 더해 계산했다. 보드 모형의 봇
시뮬레이션은 아직 없다.

### A. 계절마다 한 번 돌리고, 남은 체력으로 더 한다 (지금 규칙 전부 유지)

- 한 번 돌림 = 한 계절. 멈춘 칸의 선택이 그 계절의 첫 행동이고, 체력이 남으면 지금처럼 그 장소의 행동을 더 한다.
  휴식 +60 / +20, 새 계절 +30, 4계절 30년 규칙이 모두 그대로다.
- 계절당: 돌림 3 + 칸 5 + 추가 행동 1.02 x 4.5 + 정산 3 = 약 15.6초, 사건은 칸으로 들어가 따로 안 듦.
  **판당 약 27분** (지금 29.7분).
- 구현 크기: 중대. 보드 모듈(칸 표, 이동, 갈림길) + 엔진에 `spin` 단계 + 보드 화면. 행동 엔진과 밸런스 대부분 재사용.
  약 1,200줄, 시뮬 봇에 이동 정책 추가.
- API: 변화 없음(턴 = 계절 120 이하, 계절당 행동 수 지금과 같음).
- 약점: 돌림 뒤에도 지금의 "행동 여러 번" 화면이 남아 루즈함이 그대로일 수 있다.

### B. 체력 없이 순수 이동, 계절은 보드 구간

- 한 번 돌림 = 한 턴. 고리 16칸(계절당 4칸)을 1~6으로 돈다. 체력 · 휴식 · 계절당 여러 행동이 없어진다.
- 한 해 약 4.6번 돌림 x (돌림 3 + 칸 5 + 사건 칸 2.4) = 약 48초. **완주 약 24분, 평균 약 21분**.
- 구현 크기: 대. 엔진 진행 루프 재작성, 체력 관련 확률 보정 · 결과 줄 삭제, 11개 엔딩 전부 재밸런스,
  dominance / outcomes / simulate 검사 다시 맞춤. 약 2,500줄.
- API: 턴을 돌림 수로 세면 판당 약 137번(최악 1만 계속 나오면 480번)이라 MAX_TURNS 120을 넘는다.
  서버에 보내는 `turn`을 "지난 계절 수"로 유지하면 상한은 그대로 두어도 된다. 아니면 MAX_TURNS를 240으로 올리고
  룰렛을 2~6으로 바꿔야 한다. flights <= 5 x turns는 어느 쪽이든 넉넉하다.

### C. 혼합: 계절마다 한 번 돌리고, 추가 행동은 하나까지 (추천)

- 한 번 돌림 = 한 계절(나이 · 계절 · 120계절 그대로). 멈춘 칸의 선택은 체력을 쓰지 않는다. 체력은 "추가 행동
  하나"의 문턱으로만 쓴다(그 장소의 행동 1개, 지금의 소모량). 계절이 끝나면 체력 +30, 휴식 칸에 멈추면 +60.
  "한 계절에 여러 번 행동"은 칸 행동 + 추가 행동 1개로 줄어든다(기존 규칙에서 바뀌는 유일한 점).
- 계절당: 돌림 3 + 칸 5 + 추가 행동 0.7 x 4.5 + 정산 2 = 약 13.2초. **판당 약 23분**.
- 구현 크기: 중대. A와 같은 보드 모듈 + 장소별 선택지 필터, 체력 규칙 단순화, 밸런스 부분 재조정
  (계절당 행동이 2.02 → 약 1.7). 약 1,400줄.
- API: 변화 없음(턴 = 계절, 계절당 행동 2 이하, 점수 최고 지금 66,700으로 340,000에 여유).

### 추천

**C**. 사용자가 짚은 루즈함(계절마다 여러 번 고르고 쉬기)을 가장 직접 줄이면서 나이 · 계절 · 엔딩 · 서버 상한을 그대로
둔다. 작업은 (1) 보드 모듈과 칸 표, (2) 엔진 `spin` 단계와 시뮬 봇, (3) 보드 화면과 룰렛, (4) 재밸런스와 문서 순서로
나누어 PR 하나씩 낸다. 먼저 (1)+(2)로 봇 시뮬레이션을 돌려 판 길이와 엔딩 분포를 확인한 뒤 화면을 만든다.

## 6. 이번 진단에서 본 루즈함의 원인 (참고)

1. 행동 하나에 세 번 누르고 결과 시트를 닫고, 거의 매 계절 휴식을 따로 눌렀다(계절당 약 9~11번 클릭).
2. 대부분의 행동에 1.6초 잠긴 룰렛이 돌았다(이번 PR에서 0.7초, 누르면 멈춤).
3. 중반이 비슷했다: 이벤트 29개가 판당 평균 2.5~3.8번 반복, 새 일이 없는 계절이 약 58%, 3~12년 차에 빚이 남아
   자금이 제자리였다(이번 PR에서 이벤트 9개 추가).
