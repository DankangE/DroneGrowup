# 파일럿 키우기 — 스토리와 이벤트 대본

게임에 나오는 문장은 모두 `src/game/data.ts`에 있다. 이 문서는 줄거리와 이벤트 구성을 한눈에 보기 위한 요약이고,
수치가 다르면 `data.ts`가 맞다. 표의 "굴림"은 기본 성공률이며 능력치 보정이 붙는다.

## 줄거리

**1막 — 강의실 맨 뒷자리 (20세~)**
드론학과에 막 들어온 스무 살. 통장에는 60만원이 있다. 이론 수업과 시뮬레이터, 비행장 실기로 경험치를 쌓고,
편의점과 촬영 보조 알바로 생활비를 번다. 자격증 과정 수강료 300만원은 은행에서 빌린다. 실기 시험은 측풍 한 번에
떨어질 수 있고, 떨어져도 수강료는 돌아오지 않는다.

**2막 — 일거리를 찾아서**
조종자 증명서에 이름이 찍히면 프리랜서 파일럿이다. 입문 기체로 웨딩 촬영부터 시작해, 번 돈으로 방제 드론과 경차를
사고, 열화상 카메라를 달고, 교량과 풍력발전기로 올라간다. 풍력발전기 블레이드 점검은 한 번에 200만원이지만
실패하면 150만원을 물어내고, 운이 나쁘면 기체가 떨어진다. 정비를 미룬 기체는 더 자주 떨어진다.

**3막 — 갈림길**
어느 정도 날아 보면 길이 갈린다.
- 월급을 받는 **회사 직원**: 안정적이지만 승진 심사는 번번이 운이다. 구조조정 소문과 스카우트 제안이 온다.
- 가르치는 **교관**: 교수력을 쌓아 평가조종자가 되고, 큰 빚을 내 교육원을 세운다. 수강생을 모으고 실습장을
  늘려 국가지정 전문교육기관 인가에 도전한다.
- 내 이름으로 일하는 **1인 사업자**: 단가가 오르고 단골 계약이 생긴다. 여기서 멈춰도 좋은 엔딩이다.
- 사람을 뽑는 **법인 대표**: 채용, 영업, 공공 입찰, 자체 기체 개발, 투자 유치. 월급날은 계절마다 돌아온다.
- 사람을 모으는 **협회 임원**: 봉사와 모임으로 인맥을 쌓아 이사가 되고, 지지율을 모아 부회장, 회장 선거에 나간다.

**4막 — 서른여덟**
18년이 지나면 그 자리가 곧 엔딩이다. 상장한 회사의 대표일 수도, 회장 선거에서 떨어진 이사일 수도, 여전히 조종기를
잡은 프리랜서일 수도, 독촉 문자를 받는 빚쟁이일 수도 있다.

## 장소 (탑 뷰 지도)

학교, 비행장, 시험장, 집, 시내, 상점, 정비소, 은행, 농장, 건설 현장, 교량, 풍력단지, 해안, 촬영 스튜디오,
사무실, 본사, 교육원, 협회 회관. 행동과 이벤트는 저마다 한 장소에 속하고, 드론이 그 장소로 날아간다.

## 돌발 이벤트

이벤트 선택지는 체력을 미리 소모하지 않는다. 체력은 선택 결과에 따라 오르거나 내린다. 이벤트 굴림에도 현재 체력에 따른 성공률 보정이 적용된다(80 이상 +4%p, 40 이상 80 미만 보정 없음, 20 이상 40 미만 -8%p, 20 미만 -20%p).

### 장비 손실 (자격증 취득 후 공통)

| 이벤트 | 선택지 |
|---|---|
| **정비 경고등** — 기체 상태 34% 이하일 때. 모터에서 소음이 난다. | 일정을 미루고 정비한다 (비용 50, 기체 상태 100%로 설정) / 그냥 띄운다 (45%: 무사 / 실패: 드론 -1, 추락 횟수 +1, 기체 상태 60%로 설정) |
| **태풍 예보** — 기체를 둘 곳이 마땅치 않다. | 격납 창고를 빌린다 (비용 20, 체력 +10) / 베란다에 둔다 (60%: 무사 / 실패: 기체 상태 -40, 체력 -15) |
| **장비 가방 분실** — CCTV에 누군가 들고 가는 모습이 찍혔다. | 사례금을 걸고 찾는다 (비용 40, 되찾음) / 신고하고 기다린다 (40%: 체력 -5 / 실패: 장비 -1, 체력 -10) |
| **조류 충돌** — 까치 떼가 기체로 달려든다. | 수동으로 착륙시킨다 (45% + 조종 실력 보정: 조종 실력 +5, 경험치 +4 / 실패: 드론 -1, 추락 횟수 +1, 기체 상태 60%로 설정) / 즉시 비상 착륙 (기체 상태 -25) |
| **중고 기체 급매** — 시운전은 안 된다고 한다. | 산다 (비용 150, 55%: 드론 +1, 기체 상태 90%로 설정 / 실패: 고철) / 지나친다 (기체 상태 +15) |

### 학생

| 이벤트 | 선택지 |
|---|---|
| **드론 영상 공모전** | 밤새워 출품한다 (35% + 조종 실력 보정: +120, 평판 +2, 경험치 +4, 체력 -15 / 실패: 체력 -40, 이론 -3) / 수업에 집중한다 (이론 +8) |
| **선배의 연락** | 따라간다 (+50, 경험치 +5, 조종 실력 +2, 체력 -15) / 과제를 한다 (이론 +8, 경험치 +2) |
| **동아리 레이싱 대회** | 출전한다 (45% + 조종 실력 보정: +40, 조종 실력 +8, 경험치 +5, 평판 +3, 체력 -10 / 실패: -30, 조종 실력 +2, 체력 -25) / 관전한다 (이론 +3, 체력 +10) |
| **"2주 완성" 속성반 전단** | 등록한다 (비용 60, 30%: 이론 +14, 조종 실력 +10, 경험치 +6 / 실패: 체력 -10) / 버린다 (이론 +3) |

### 프리랜서 · 1인 사업자

| 이벤트 | 선택지 |
|---|---|
| **수상한 의뢰** — 비행 금지 구역, 단가는 세 배. | 몰래 찍는다 (55%: +260 / 실패: -100, 평판 -8) / 거절한다 (평판 +2) |
| **단골의 소개** | 바로 일을 받는다 (+60, 평판 +2, 체력 -10) / 식사 자리를 만든다 (인맥 +5, 평판 +1) |
| **청년 드론 창업 지원사업** | 지원한다 (40% + 경영 보정: +300, 경영 +2, 체력 -15 / 실패: 경영 +1, 체력 -25) / 넘긴다 (조종 실력 +4) |
| **드론 박람회 초청** (자격증 취득 후 전 직군) | 부스를 낸다 (비용 60, 60%: +110, 평판 +5, 인맥 +5, 체력 -15 / 실패: 인맥 +2, 체력 -20) / 관람만 한다 (인맥 +1, 이론 +4) |
| **친구의 부탁** (전 직군) | 빌려준다 (비용 50, 55%: +75, 인맥 +3 / 실패: 인맥 +1) / 거절한다 (인맥 -1) |

### 회사 직원

| 이벤트 | 선택지 |
|---|---|
| **구조조정 소문** | 버틴다 (65% + 직급 보정 + 평판 보정: 평판 +2 / 실패: +120, 직급 0으로 초기화, 프리랜서로 복귀) / 희망퇴직한다 (+260, 직급 0으로 초기화, 프리랜서로 복귀) |
| **경쟁사의 스카우트** | 옮긴다 (60%: 직급 +1 / 실패: 평판 -4) / 남는다 (평판 +2) |
| **신사업 TF 모집** | 자원한다 (55%: 경험치 +10, 경영 +7, 평판 +3, 체력 -20 / 실패: 경영 +2, 평판 -2, 체력 -35) / 사양한다 (이론 +4, 체력 +10) |

### 교관 · 교육원

| 이벤트 | 선택지 |
|---|---|
| **교육생 기체 추락** | 내 책임으로 수습한다 (비용 50, 평판 +4, 교수력 +2) / 보험으로 처리한다 (60%: 이론 +2 / 실패: 평판 -5, -40) |
| **우수 교관 표창 후보** | 공적서를 낸다 (45% + 교수력 보정: +80, 평판 +8, 체력 -10 / 실패: 체력 -20) / 후배에게 양보한다 (인맥 +5) |
| **옆 동네 저가 교육원** | 수강료를 내린다 (비용 80, 수강생 +4) / 합격률로 승부한다 (50% + 교수력 보정: 수강생 +4, 평판 +4 / 실패: 수강생 -5) |
| **교육원 안전 점검** | 시설을 보강한다 (비용 120, 평판 +4) / 서류만 맞춘다 (55%: 통과 / 실패: -150, 평판 -6) |

### 사업 (1인 사업자 · 법인)

| 이벤트 | 선택지 |
|---|---|
| **세무조사 통지** | 세무사에게 맡긴다 (비용 80, 경영 +2) / 직접 대응한다 (45% + 경영 보정: 경영 +6 / 실패: -200, 경영 +1) |
| **대기업의 하청 제안** | 받는다 (62%: +250, 계약 +1, 평판 +2 / 실패: -110, 평판 -2) / 거절한다 (평판 +1, 경영 +1) |
| **에이스의 사직서** | 연봉을 올려 붙잡는다 (비용 150, 평판 +1) / 보내 준다 (50%: 직원 -1 / 실패: 직원 -1, 계약 -1) |
| **엔젤 투자자의 제안** | 투자를 받는다 (+1,000, 기업가치 +2,000, 인맥 +4) / 지분을 지킨다 (경영 +4) |
| **경쟁사의 덤핑** | 가격을 맞춘다 (비용 90, 경영 +2) / 품질로 설득한다 (55% + 평판 보정: 평판 +4 / 실패: 계약 -1) |
