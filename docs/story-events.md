# 파일럿 키우기 — 스토리와 이벤트 대본

19세 봄부터 70세 봄까지 직업·집·가족·자산을 선택하며 살아간다.
공통 38사건은 `src/life/data.ts`, 새 82사건은 `src/life/events-a.ts`~`events-h.ts`에 있다.
조건 변환은 `src/life/compat.ts`가 맡고, 규칙과 수치의 기준은 [life-board 명세](design/life-board.md)다.
아래 굴림은 기본 성공률이며 실제 확률은 엔진이 계산해 표시한다.

## 돌발 이벤트

이벤트 선택지는 체력을 미리 소모하지 않는다. 체력은 선택 결과에 따라 오르거나 내린다. 이벤트 굴림에도 현재 체력에 따른 성공률 보정이 적용된다(80 이상 +4%p, 40 이상 80 미만 보정 없음, 20 이상 40 미만 -8%p, 20 미만 -20%p).

### 장비 손실 (자격증 취득 후 공통)

| 이벤트 | 선택지 |
|---|---|
| **정비 경고등** — 기체 상태 34% 이하일 때. 모터에서 소음이 난다. | 일정을 미루고 정비한다 (비용 50, 기체 상태 100%로 설정) / 그냥 띄운다 (45%: 무사 / 실패: 드론 -1, 추락 횟수 +1, 기체 상태 60%로 설정) |
| **태풍 예보** — 기체를 둘 곳이 마땅치 않다. | 격납 창고를 빌린다 (비용 20, 체력 +10) / 베란다에 둔다 (60%: 무사 / 실패: 기체 상태 -40, 체력 -15) |
| **장비 가방 분실** — CCTV에 누군가 들고 가는 모습이 찍혔다. | 사례금을 걸고 찾는다 (비용 40, 되찾음) / 신고하고 기다린다 (40%: 체력 -5 / 실패: 장비 -1, 체력 -10) |
| **조류 충돌** — 까치 떼가 기체로 달려든다. | 수동으로 착륙시킨다 (45% + 조종 실력 보정: 조종 실력 +5, 경험치 +4 / 실패: 드론 -1, 추락 횟수 +1, 기체 상태 60%로 설정) / 즉시 비상 착륙 (기체 상태 -25) |
| **중고 기체 급매** — 시운전은 안 된다고 한다. | 산다 (비용 150, 55%: 드론 +1, 기체 상태 90%로 설정 / 실패: 고철) / 지나친다 (기체 상태 +15) |

### T12 해석과 명세 예외

- 복권·투자 금액과 확률은 명세 그대로다. 코인 광풍의 2회 제한은 응답이 아니라 추첨 횟수를 센다.
- 금융 위기와 대세 상승의 펀드 변동은 사건이 뜨는 즉시 적용한다. 위기의 +15%p는 팝업에서 실제 입금한 경우 다음 연말 한 번만 적용한다. 팝업과 사건 직접 인출에는 수수료를 붙이지 않는다.
- 부상·간병·운동 기간은 현재 계절의 마감을 포함한다. 번아웃은 회복 전 마감 체력이 40 미만인 연속 계절을 센다. 질병의 체력 상한은 기존 최소 상한 60을 지킨다.
- 해외 연수는 급여·생활비·가족·연말 정산을 유지하며 두 계절을 마감한다. 이동 사건은 통행료·출발 수당 없이 위치를 바꾼다. 패스트트랙의 주 능력치는 기존 직무 연습의 첫 능력치(엔지니어·관제사: 이론, 점검·촬영·레이서: 조종)다.
- 별장은 기존 주택 보유 한도를 지키며, 자가가 없으면 거주 주택, 있으면 추가 주택이 된다. 조직 가치는 기존 순자산 평가식(법인 또는 교육원 + 보유 가게)을 따른다. 매각 성공 시 해당 조직과 가게를 처분하고, 승계 준비는 결산에만 10%를 더한다.
- T11의 기대값·최악값 비교를 유지하면 명세에 예외가 있다. 기존 `headhunter:1>2`에 더해, 이론이 낮을 때 `invest_scam:0>1`, 순자산이 높을 때 `tax_audit2:0>1`이 검출된다. 제목·응답·수치를 바꾸지 않고 `dominance-life.ts`의 명시 예외로 출력한다. 다른 우월 관계는 실패 처리한다.
