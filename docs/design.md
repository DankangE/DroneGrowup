## T24 시간 측정 (2026-11-26)

PM이 전달한 **F5 이전 약 18초/계절**은 204계절 환산 약 **61.2분**이다. 이전 고정 모형
14.9초/계절(50.66분)과 달랐다. 이 세션의 `npm run check:board -- timed`는
`listen EPERM: operation not permitted 127.0.0.1`로 중단됐다. **F5 이후 브라우저 실측은 미확인**이다.

읽기 대기는 `scripts/life-time-data.ts` 한 곳에 두며 변경하지 않았다. 공통 모형은 실제 선택,
이동 프레임 수, 결과 팝업 수, 시트 진입을 합산한다. 시뮬레이션의 게임 경로·경제 표는 유지하면서

72계절 계산 합계 943.44초, 204계절 환산 44.55분은 **통과 근거가 아니다**. PM은
`npm run check:board -- timed 390x844`를 실행한다. 실제 클릭, 읽기 대기, 자연스러운 애니메이션,
마지막 계절의 결과 닫기까지 측정하며, 지도 주입은 시작할 때 한 번뿐이다. 성공적으로 수집한
원시 측정은 `docs/life-timing.json`에 저장된다. 다른 화면 크기의 timed 실행은 진단용이다.

`MODEL_SECONDS`는 유효한 측정의 평균이며, 측정이 없으면 `null`(uncalibrated)이다.
시뮬레이션은 동일 72계절의 실측 합계/모형 합계를 보정계수로 사용하고, 정책별 실제 행동 빈도에
적용한다. 소스 지문이 달라지거나 6지도 × 12개의 유효한 구간이 없으면 시간 20항목은
**FAIL(실측 미확인)**이다. 전체 45~55분, 정책 40~60분, 시기 16/20/14±4분 기준은 그대로다.
재측정 후 `npm run simulate:life`로 판정한다. 실측 없이 대기 시간을 임의로 줄이지 않았으며,
실측이 목표를 넘으면 콘텐츠와 읽기 시간을 보존하며 UI 애니메이션을 조정하고 다시 측정해야 한다.

16정책 × 300시드의 전체 순수 시뮬레이션 시간은 54.66분(시기 17.13/21.74/15.79)이다.
지도별 초반 12계절 표본과 생애 전체 정책은 선택 빈도가 달라 같은 평균이 아니다.
전체 실행은 각 실험 4,800판, 막힘·오류 0, 182.71초, 60 PASS / 61 FAIL(exit 1)이다.
시간 20개 실측 미확인과 비시간 41개 미달을 그대로 보고한다. `npm test` 979/979,
`npm run typecheck` PASS. `verify`와 커밋은 실행하지 않았다.

기울임 보기는 ‘내 인생 → 설정’에서 바꾼다. 기본은 꺼짐이며 기존 저장 모듈의 계정별 로컬 키
`pilot-growup:settings:v2`를 사용한다. 보드와 칸 표면은 28도, 글자·말·건물과 DOM 누름 영역은
역투영/역회전으로 세운다. 브라우저 검사에 6지도·4크기·두 모션 설정의 실제 도착 칸 클릭,
설정 재로드, 기울임 상태의 키보드 12계절을 추가했다. 포트 제한 때문에 이 검사는 PM 실행이 필요하다.

## T23 전환 검증

실행 시간을 제외한 전환 전후 보고서는 완전히 같다. 결과는 T15와 같은
