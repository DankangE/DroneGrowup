# 파일럿 키우기

드론학과 학생으로 시작해 선택과 운으로 커리어를 키우는 탑 뷰 선택 게임.
자격증을 따고, 일거리를 찾고, 장비를 올리고, 회사·교육원·협회·1인 사업 가운데 길을 골라 50세에 11가지 엔딩 중
하나를 본다. 1년은 네 계절이고 체력이 남는 동안 한 계절에 여러 번 행동한다. 끝까지 가면 35분 안팎.

```
npm install
npm run dev        # 개발 서버
npm run verify     # 타입 검사, 빌드, 단위 테스트, 밸런스 시뮬레이션, 헤드리스 플레이 테스트, 무스크롤 레이아웃 검사
```
